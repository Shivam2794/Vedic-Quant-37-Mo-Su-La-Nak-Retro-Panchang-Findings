strategy("MA Cross TQQQ - 50 Day Filter", 
         default_qty_type = strategy.percent_of_equity, 
         default_qty_value = 100, 
         overlay=true)

// Leverage parameter (for display purposes - TradingView handles this via account settings)
lvg = input.float(defval=1, step = 0.05, title = "Leverage")

// MA Crossover parameters
fastLength = input.int(10, "Fast MA Length")
slowLength = input.int(64, "Slow MA Length")

// Trend filter parameter
trendFilterLength = input.int(50, "Trend Filter MA Length", minval=0)
// Set to 0 to disable trend filter

// Calculate MAs
fastMA = ta.ema(close, fastLength)
slowMA = ta.ema(close, slowLength)

// Calculate trend filter MA (if enabled)
trendMA = trendFilterLength > 0 ? ta.sma(close, trendFilterLength) : na

// Trend filter condition: price must be above trend MA (if filter enabled)
aboveTrend = trendFilterLength == 0 ? true : close > trendMA

// MA Crossover signals
crossover = ta.crossover(fastMA, slowMA)
crossunder = ta.crossunder(fastMA, slowMA)

// Buy condition: fast MA crosses above slow MA AND price is above trend filter
bcond = crossover and aboveTrend

// Sell condition: fast MA crosses below slow MA
scond = crossunder

// Position sizing
contracts = strategy.equity / close

// Entry and exit logic
if bcond
    strategy.entry("MACrossLE", strategy.long, comment="MACrossLE", qty = contracts * lvg)

if scond
    strategy.close("MACrossLE")

// Plot MAs
plot(fastMA, color = color.blue, linewidth = 1, title = "Fast MA (10)")
plot(slowMA, color = color.orange, linewidth = 1, title = "Slow MA (64)")

// Plot trend filter MA (if enabled)
plot(trendFilterLength > 0 ? trendMA : na, color = color.yellow, linewidth = 2, title = "Trend Filter MA")

// Highlight when price is above trend filter (if enabled)
bgcolor(trendFilterLength > 0 and aboveTrend ? color.new(color.green, 95) : na, title = "Above Trend Filter")

Your biggest gap is transition detection. Knowing the regime in hindsight is easy. Detecting the shift in real time is the hard part.

[2026-04-28T12:39:18.7990000-05:00] quant_trades: Ernest Chan - Algorithmic Trading: Winning Strategies and Their Rationale. Best on-ramp. Covers transaction cost modeling, mean reversion vs momentum at intraday scales, and is written for retail to small fund scale. His earlier Quantitative Trading is also good but more introductory.

Marcos López de Prado - Advances in Financial Machine Learning. Non-negotiable for what you are wanting to do The chapters on information-driven bars (volume/dollar/imbalance bars), fractional differentiation, triple-barrier labeling, and purged k-fold CV are exactly the tools that make sub-1H backtests not lie to you. Dense but worth every page.

Microstructure and execution 

Álvaro Cartea, Sebastian Jaimungal, José Penalva - Algorithmic and High Frequency Trading. The textbook on limit order book dynamics, optimal execution, and fill modeling. Mathematically heavier but this is where slippage stops being a fudge factor and becomes a model.

Robert Kissell - The Science of Algorithmic Trading and Portfolio Management. More accessible than Cartea et al. for transaction cost analysis specifically. Practitioner focused.

Larry Harris -  Trading and Exchanges: Market Microstructure for Practitioners. Older but still the clearest plain-English explanation of how markets actually work mechanically, who provides liquidity, how orders interact, and why spreads exist. If you don't have a microstructure foundation, this fills it without math.

some deeper but more optional:

Irene Aldridge -  High Frequency Trading: A Practical Guide. Decent overview, somewhat dated but covers the landscape.

Barry Johnson - Algorithmic Trading and DMA. Execution-focused, good for understanding order types and venue mechanics.

Marcos López de Prado - Machine Learning for Asset Managers. Shorter follow-up to Advances. Good if you want the condensed version after reading the first one.
