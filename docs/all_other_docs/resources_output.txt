[2026-01-17T08:37:25.2550000-06:00] the_biggest_rick: **Quant Rick (2:31pm)**
I’d actually advise doing this slightly differently, because there are a few things not accounted for. I understand what you’re doing, but let’s change it a bit.

First, split the data. You have a fairly large dataset — you’re going back to 2010, I believe — so split it 80–20. Take the training set and split it further into, let’s say, six periods. Make sure you calculate embargo periods and use a cappershed cross-validation. Then test it walking forward interchangeably on a period in the test set, as you normally would, and continue like that.

This accounts much more for some of the natural problems caused by non-stationarity. If you simply do a standard walk-forward, it’s leaking in a sense, because the time series coming in are never identical. Walking forward like that becomes inconsistent with true generalization.

**Anonymous (2:32pm)**
Okay, thank you. Should I keep the same technicals — MA and ATR — and adjust exposure based on ATR?

**Quant Rick (2:34pm)**
Generally, I like to avoid making any adjustments to exposure at this stage. The goal is to make sure the base strategy actually works first, and then maybe play with exposure later. Otherwise, you’re introducing a bias that could overshadow your results.

If you’re taking different position sizes, the question is: why? I don’t really see the point early on. The point is to have a working strategy first and then adjust exposure afterward. If you start adjusting exposure right away — for example, for volatility — you might mask later problems or under-the-hood issues you wouldn’t otherwise see.

So start very bare bones.
